# Mini Project 02 - Git Workflow Simulator

## Project Objective

This project simulates a professional GitHub team workflow involving:

- Feature branches
- Pull Requests
- Code Reviews
- Merge Conflicts
- Release Tagging

## Skills Applied

- Git
- GitHub
- Branching Strategy
- Collaboration Workflow
- Documentation

## Workflow Implemented

1. Created feature branches
2. Developed features independently
3. Created Pull Requests
4. Reviewed and merged code
5. Simulated merge conflicts
6. Resolved conflicts
7. Created release tag v1.0
